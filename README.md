# 1人だけ、ちがう。

スマホでURLを開くだけで、10人くらいまで遊べる会話ゲーム。
ワードウルフ・人狼・ウミガメのスープを混ぜて、ルールを1行まで削ったもの。

**ルール: 全員にお題が配られる。でも1人だけ、少し違うお題。それが誰かを当てる。**

## 遊び方（1ラウンド 8分くらい）

1. **配る** — 全員のスマホに問いが1つ出る。9人は同じ問い、1人だけ違う問い。
   自分がどちら側かは分からない。
2. **1周する** — 画面に出た順番で、1人20秒。**答えだけ**を口で言う。
   お題そのものは絶対に読み上げない。
3. **質問タイム** — 3分。誰にでも質問できる。「なんでそれ選んだの?」で詰める。
4. **せーので指差し** — 全員同時に、怪しい人を指差す。一番多い人が1人選ばれる。
5. **結果** — 全員で同時に「正解を見る」を押す。各自の画面に答えが出る。

### 勝敗

| 指差しで選ばれたのが | 結果 |
|---|---|
| 少数派 | 多数派の勝ち。ただし少数派は**多数派のお題を口で当てられたら逆転勝ち** |
| 多数派 | 少数派の勝ち |

### 個人ミッション（任意・ONが初期値）

勝敗とは別に、全員に秘密の裏目標が配られる（「たしかに」を3回言う、など）。
結果画面で順番に読み上げて、達成できたか申告する。
会話が変な方向に転がるので、初対面が混ざる会ほど効く。

## 使い方

1. ホストが **部屋をつくる** → あいことば・人数・ジャンルを決める
2. **招待リンクをコピー** してLINEなどに貼る → 全員がタップすれば設定は自動で揃う
3. リンクが配れないときは、あいことば・人数・ジャンルを口で伝えて、
   各自 **部屋に入る** から同じ設定にする（1つでも違うとお題がズレる）
4. 全員が自分の番号を選ぶ（「1番いきます」「じゃあ2番」と声に出して重複を避ける）

ラウンド番号が人によってズレたら、上部バーの `−` `＋` で合わせる。

## しくみ

サーバーを使っていない。静的ファイル3つだけで動く。

**あいことば・人数・ジャンル・ラウンド番号** の4つをシードにした決定論的な乱数で、
お題・少数派の番号・発言順を計算している。4つが同じなら、どのスマホで計算しても
まったく同じ結果になる。だから通信も同期もいらない。

- お題は「シャッフルした山札」から順に引くので、同じ部屋なら一巡するまで重複しない
- 多数派/少数派どちらのお題になるかは毎ラウンド入れ替わる
- 個人ミッションは別の乱数列を使うので、ミッションのON/OFFが人によって違ってもお題はズレない

この設計上、**得点の自動集計とロビー表示はできない**。必要になったらリアルタイム同期版
（Cloudflare Workers など）に作り替えることになるが、お題データと画面はそのまま流用できる。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面とスタイル（全部入り） |
| `app.js` | 配役の計算・画面遷移・タイマー |
| `topics.js` | お題データとミッション。**増やすならここだけ触ればいい** |

### お題を足す

`topics.js` の `TOPIC_SETS` に `{ a: '...', b: '...' }` を追加するだけ。

良いお題の条件:

- **a と b の答えが半分くらい重なる** こと。全然違うとすぐバレるし、同じすぎると当たらない
- 誰でも10秒で答えを1つ思いつくこと
- 答えを聞いて「なんで?」と突っ込みたくなること

悪い例: 「好きな食べ物」/「嫌いな食べ物」→ 答えが被らないので一瞬でバレる
良い例: 「疲れきってるときに食べたいもの」/「元気があり余ってるときに食べたいもの」

現在: 飲み会 50組 / 家族 35組、ミッション 20種。

## ローカルで動かす

```
python3 -m http.server 8942 --directory zure
```

`.claude/launch.json` に `zure` として登録済み。
