# ゲーム（1人だけ、ちがう）

スマホでURLを開くだけで、10人くらいまで遊べる会話ゲーム。
ワードウルフ・人狼・ウミガメのスープを混ぜたもの。

**ルール: 全員に3つのキーワードが配られる。でも1人だけ、そのうち1つが違う。
連想した言葉を見比べて、それが誰かを当てる。**

## 遊び方

1. **名前を登録** — 全員がURLを開き、名前とあいことばを入れて参加
2. **ロビー** — 参加者が全員の画面にリアルタイムで並ぶ。誰かが「このメンバーでスタート」を押すと始まる
3. **回答** — 3つのキーワードが出る。そこから**連想した言葉をひとつ**入力する。
   異端だけは「あなたは異端です／3つのうち1つが違います」と表示される
   （**どれが違うかは本人にも分からない**）
4. **一覧** — 全員の回答が揃うと、全員の名前と答えが一覧で出る。
   並びは**回答が届いた順**（早く出した人が上）。ここで話し合う
5. **投票** — 一覧の中から「お題が違う人」を1人選ぶ
6. **結果** — 全員が選び終わると自動集計。異端・両方の3語（違う1語は色付き）・
   誰が誰に投票したかが開示される

回答が出そろった瞬間と、全員が選び終わった瞬間には **3・2・1 のカウントダウン**をはさむ。

### 勝敗

| 条件 | 結果 |
|---|---|
| 最多票がちょうど1人で、それが異端 | **多数派の勝ち** |
| それ以外（異端が逃げ切った・票が割れた） | **異端の勝ち** |

### 殺害（異端だけの特殊ルール）

異端が選んだ相手が、**その相手も異端を選んでいた**場合（相互投票）、異端はその人を殺害する。
殺害された人の画面にはドクロと「あなたは殺害されました」が出る。

勝敗とは独立に判定されるので、**捕まった異端も道連れを1人つくれる**。
実際、全員が異端を正しく指した場合は必ず相互投票が成立するため、異端は必ず1人を道連れにできる。

## しくみ

Cloudflare Workers + Durable Objects。**あいことば1つにつき Durable Object が1つ**でき、
そこに全員の状態（参加者・お題・回答・投票）が集まる。各スマホは WebSocket でつながり、
サーバーが配る状態をそのまま描画する。

**お題は接続ごとに出し分けている。** 回答フェーズで全員に両方のお題を配ってしまうと
ゲームが成立しないので、`viewFor()` で「その人に見せてよい情報」だけを詰めて送る。
異端が誰かも、多数派の3語も、結果フェーズになるまでクライアントには送られない。
**異端本人には「異端である」ことだけ伝え、3語のどれが違うかは伝えない。**

その他:

- 途中参加できる。ただし進行中のラウンドには入らず（お題も配られない）、次のラウンドから参加する
- 切断すると全員の画面で名前が薄くなる。つなぎ直せば同じ人として復帰する（ブラウザに保存したIDで識別）
- **電池切れなどで誰かが戻ってこない場合**、その人を待って進行が止まる。
  そのときは「切断中の◯◯を待たずに進む」ボタンが出るので、誰が押しても外して進める。
  今つながっている人は外せないので、勝手に追い出すことはできない
- 電波が切れたら自動で再接続する。ただし**自分で「退出」したら二度とつなぎ直さない**
  （つなぎ直すと前の部屋に引き戻され、別の部屋に入れなくなる）
- 最初の画面では自動で参加しない。リロードすると名前の入力からやり直しになるが、
  勝手に前の部屋へ戻されるより害が小さい
- お題は部屋ごとに履歴を持ち、全部出し切るまで重複しない
- 一覧の並び順は回答が届いた順。回答フェーズ中に書き直すと最後尾に回る。
  一覧が出たあとは書き直せない
- 3語の表示順は毎ラウンドシャッフルする。違う語がいつも同じ位置だと学習されるため
- カウントダウンは各端末が受信直後に数える。サーバーのアラームで待たせると
  発火しなかったときに全員が固まるため（実際に一度、例外でカウントダウンが
  止まってゲームごと停止した。今は二重に保険をかけてある）

## ファイル

| ファイル | 中身 |
|---|---|
| `src/worker.js` | 入口 + 部屋（Durable Object）。ゲームのルールは全部ここ |
| `src/topics.js` | お題データ。**増やすならここだけ触ればいい** |
| `public/index.html` | 画面とスタイル |
| `public/app.js` | 通信と描画。サーバーの状態を写すだけで、判定は持たない |
| `wrangler.toml` | Cloudflare の設定 |

### お題を足す

`src/topics.js` の `TOPIC_SETS` に `{ a: '...', b: '...' }` を追加するだけ。
足したら `npx wrangler deploy` で反映。

**3語は必ず別々の分野から選ぶ。** 同じ世界の言葉を並べると答えが1つに決まり、連想の余地が消える。

だめ: 麺 / スープ / 替え玉 → 全員が「ラーメン」としか書けない。会話にならない
よい: 消しゴム / ろうそく / 石けん → 分野はバラバラ。「使うと減る」でつながる

**3語をつなぐのは共通する性質ひとつだけ。** 色・形・音・温度・動き・変化・扱われ方など。
その性質に気づくのが遊びの中心。

**差し替え語は別の性質でつながるようにする。** 同じ性質のままだと異端も同じ答えを書き、誰も当てられない。

例: トマト / 消防車 / ポスト（赤い）→ ポストを「救急車」に
→ 多数派は「赤」、異端は消防車と救急車に引かれて「サイレン」「緊急」へ寄る

足すときの手順:

1. 3語が本当に別分野か確かめる（**2語でも同じ分野なら作り直す**）
2. 多数派の3語に共通する性質を1つ言えるか確かめる
3. 差し替え後の3語に、別の共通点が立つか確かめる
4. それでも両方から出そうな答えが1つはあるか確かめる（無ければ差が開きすぎ）

現在: 飲み会 50組 / 家族 35組。

## 開発

```
npm install
npx wrangler dev          # ローカル。Cloudflareのアカウントは不要
npx wrangler deploy       # 本番に反映
```

`.claude/launch.json` に `zure`（ポート8788）として登録済み。
